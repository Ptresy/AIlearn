# Markdown语法学习

## 一. 基础知识

### 1. 常用编辑器

Vscode或Typora

### 2.注意点

Markdown语法不支持中文符号.

在Typora上进行编辑时,应养成在英文符号后面加上一个空格的习惯,使得Typora上的笔记在其他编辑器中兼容.

### 3.强调

对想要强调的内容前后加上"**"或"__"

或者直接框选需要强调的内容,然后按下CTRL+B

**你好,Markdown**

__你好,Markdown__

**你好,Markdown**

(注:斜体则为单个符号或者CTRL+I)

*你好,Markdown*

*你好,Markdown*

_你好,Markdown_

(若需要同时取斜体与强调,则取"***"或"___")

### 4.删除线

使用"~~"包围

~~你好,Markdown~~

### 5.代码

使用"`"包围, 仅限于在一行中使用

`#include <stdio.h>`

### 6.代码块

"```"加上回车,可以开启一个代码块

```c
#include <stdi.h>
    int main
    printf("hello world")
return 0
```

### 7.引用

一个">"加上一个空格即可开始引用.

引用是可以多级叠加的

> 你好
>
> 下面是二级引用
>
> > 这里是二级引用
> >
> > 

### 8.无序列表

使用"-"或者"+"然后按下空格即可开始列表

使用Tab来控制缩进

- 这是第一缩进,只需要-加上空格
- 这是第一缩进第二行,只需一下回车即可
  - 这是第二缩进,只需在创造第三行之后点一下Tab即可
- 这是回到第一缩进,只需同时按下shift和Tab即可



### 9.有序列表

只需在输入"1."之后按下空格即可

1. 这是第一缩进第一行, 只需按下1.并加上空格, 记得不是回车
2. 这是第一缩进第二行,一下回车的事
   1. 这是第二缩进第一行,还是Tab
3. 这是返回第一缩进,依旧是shift+Tab



### 10.拓展语法(需要在设置中自行打开)

1. 高亮

   使用"=="包围

   ==你好, Markdown==

   

   

2. 上下标

   上标为使用"^"包围,下标为使用"~"包围

   x^2^

   H~2~O



### 11.注释

在结尾加上`[^"一个数字"]`,然后再后面以`[^n]:`的形式加上注释

例如

> 这是最好的时代,这是最坏的时代[^1]

[^1]:出自查尔斯的*双城记*



### 12.链接

格式为"[]+()",其中中括号内是介绍文字,小括号内是网址或文内地址(注意,内部跳转只能连接到标题处)

需要跳转时按下ctrl即可

### 13.任务列表

格式: `- [ ] + 任务内容`

``` 
格式如下
- [ ] 踢足球
- [ ] 打篮球
```

注意: 中括号之间的空格不可省略

- [ ] 打篮球

- [ ] 踢足球



### 14.表格

使用" : " 和" - - -"  来说明对齐方式,

​	:--- 表示左对齐

​	:---:表示居中

​	---: 表示右对齐

使用 | 来划分格子

```
|姓名|年龄|性别|
|:---|:---:|---:|
|张三|18|男|
|李四|19|女|
```

| 姓名 | 年龄 | 性别 |
| :--- | :--: | ---: |
| 张三 |  18  |   男 |
| 李四 |  19  |   女 |



### 15.分割线

```
***
---
___
```

***

---

这是使用-进行分割

___

这是使用_进行分割
